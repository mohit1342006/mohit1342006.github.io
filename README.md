# Mohit Namdev — Developer Portfolio

A responsive personal portfolio starter built with HTML, CSS, and JavaScript.

## Run locally
1. Open this folder in VS Code.
2. Open `index.html` in your browser, or use the Live Server extension.

## Personalize before publishing
- Replace `your.email@example.com` in `index.html` with your real email.
- Replace the `#` GitHub and LinkedIn links with your profile URLs.
- Replace the sample project cards and repository links with your actual projects.
- Update the skills and skill-bar widths to match your real experience.
- Add your resume file and link it if you want a resume download button.

## Publish with GitHub Pages
1. Create a GitHub repository named `yourusername.github.io` (replace with your GitHub username).
2. Upload all files and folders from this project to the repository root.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. After deployment, visit `https://yourusername.github.io`.

No build tools or frameworks are required.
